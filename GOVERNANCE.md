# Governance

Ahmed Jawed (@ahmedjawedaj) maintains DecisionBound. Original project material is Apache-2.0.

Propose focused changes with meaningful tests, user documentation and reproducible evidence. Authorization, data boundaries, migrations, isolation, dependencies and public API changes require particular scrutiny. Follow CONTRIBUTING.md, SECURITY.md, CODE_OF_CONDUCT.md and PUBLICATION_POLICY.md. Automated checks are evidence, not independent human review or a production certification. Sensitive vulnerabilities should be reported privately through GitHub Security.
