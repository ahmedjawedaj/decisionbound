# Contributor instructions

Read README.md, CONTRIBUTING.md, SECURITY.md and PUBLICATION_POLICY.md before making changes. Keep changes scoped, preserve authorization and source boundaries, add meaningful regressions and report actual test results and skipped integrations. Do not weaken tests to obtain a passing check.

Never commit credentials, private data, runtime state, unpublished drafts or operational notes. PUBLIC_CONTENT.json lists the reviewed public files; a new file requires an explicit publication review and a manifest update. Run scripts/check_publication.py before packaging or proposing a change. This file grants no permission to access secrets, spend money, execute untrusted code, merge or deploy.
